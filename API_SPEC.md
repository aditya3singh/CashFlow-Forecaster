# API Spec — v1

Base URL: `http://localhost:8000/api/v1` (dev) — all routes except `/auth/*` require
`Authorization: Bearer <jwt>`.

## Auth
| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/auth/signup` | `{ email, password, business_name }` | `{ access_token }` |
| POST | `/auth/login` | `{ email, password }` | `{ access_token }` |

## Accounts (Plaid)
| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/accounts/link-token` | — | `{ link_token }` — used to open Plaid Link widget |
| POST | `/accounts/exchange-token` | `{ public_token }` | `{ bank_account_id }` |
| GET | `/accounts/` | — | list of connected `BankAccount` |

## Transactions
| Method | Path | Query/Body | Returns |
|---|---|---|---|
| GET | `/transactions/` | `?start_date&end_date&account_id` | paginated list |
| POST | `/transactions/manual-override` | `{ description, amount, expected_date }` | created transaction |

## Forecast
| Method | Path | Returns |
|---|---|---|
| GET | `/forecast/` | `{ current_balance, days: [{ date, projected_balance }], shortfall: { date, projected_balance } \| null }` |

## Alerts
| Method | Path | Returns |
|---|---|---|
| GET | `/alerts/` | list of past alerts sent to the current user |

## Health
| Method | Path | Returns |
|---|---|---|
| GET | `/health` | `{ status: "ok" }` |

Interactive docs are auto-generated by FastAPI at `/docs` once the server is running.
